# 3. 开发与验证

本文命令均在仓库根目录执行。先读 [架构现状](1_架构与技术现状.md)，再按 [规则对照](2_规则与实现对照.md) 判断异常是缺陷还是当前简化规则。

## 环境与启动

推荐 Node.js 22.12+、pnpm 10（`packageManager` 固定为 10.28.2）。此次验证环境为 macOS、Node.js 22.17.0。

仓库根目录的 `.npmrc` 把安装源固定为 npm 官方源：`pnpm-lock.yaml` 按官方源解析，部分内网镜像缺少其中的版本（如 `@colyseus/better-call` 1.3.3、`express-session` 1.19.0），会导致安装失败或被悄悄降级。

```bash
pnpm install
pnpm dev
```

也可在两个终端分别启动：

```bash
pnpm --filter @feed/server dev
pnpm --filter @feed/client dev
```

前端 `http://localhost:5173`，后端 `http://localhost:2567`，健康检查 `/api/health`。前端监听所有网卡，手机使用电脑的局域网 IP 访问；默认 WebSocket 会使用当前页面主机名加 `2567` 端口。需要确保电脑与手机网络互通。

| 变量                       | 用途                                                           |
| -------------------------- | -------------------------------------------------------------- |
| `PORT`                     | 后端端口，默认 `2567`                                          |
| `VITE_SERVER_URL`          | 前端完整 WebSocket 地址；部署 HTTPS 页面应使用 `wss://`        |
| `DATABASE_PATH`            | SQLite 文件路径；默认相对服务端工作目录 `./data/kraken.sqlite` |
| `RECONNECT_SESSION_TTL_MS` | 令牌有效期，默认 7 天                                          |
| `ROOM_IDLE_TTL_MS`         | 空房间保留时间，默认 24 小时                                   |
| `FTK_DEBUG=1`              | 动作与事件诊断日志                                             |

例如：

```bash
FTK_DEBUG=1 pnpm --filter @feed/server dev
```

调试日志可能包含投票投入等服务端信息，仅用于可信环境。`/api/health` 目前不检查数据库。热更新重启服务端同样会丢失内存房间；浏览器恢复令牌不能恢复已不存在的房间。

## 多人使用与恢复

1. 一位玩家创建房间，复制房间号给朋友。
2. 其他玩家输入昵称和房间号，以新玩家加入。
3. 至少 5 人，由房主开始。5–6 人快速，7 人可选，8–11 人漫长。
4. 在外部语音讨论。船长、大副、领航员选牌时保持沉默。
5. 断线后页面禁用动作，使用「恢复连接」。返回港口后也可输入房间号「恢复上次身份」。

不要用「新玩家加入」恢复旧身份。每个活动标签页保留自己的 sessionStorage；同房间的 localStorage 只存最后一次身份。返回港口不删除座位，离线座位仍计入 11 人上限。当前没有踢人、主持权转移或重新开局按钮；新一局创建新房间。

服务器允许最多 12 个临时连接，业务座位最多 11 个，多出的连接仅用于替换尚未断开的旧连接。恢复认证成功时先撤销旧连接权限，再关闭旧 socket。

## 素材处理

源文件在 `assets/picture`、`assets/models`、`assets/video`。只将前端需要的少量图片生成到 `packages/client/public/art`：

```bash
# macOS，首次需要 cwebp 时
brew install webp
bash scripts/prepare-assets.sh
```

`src/labels.ts` 中的 `art`、`navFaceArt`、`factionArt` 等对象是组件资源入口。当前共 23 张 WebP，磁盘占用约 1.3 MiB，其中大厅主图约 172 KiB；透明主体按绘制范围裁切后再缩放。既有运行时图片已入仓，普通开发不必安装 cwebp。原图、模型压缩包和视频不进入构建产物。

`public/art` 使用固定文件名，不带内容 hash；不要配置永不过期的 immutable 缓存。Vite 生成的 `dist/assets` 带 hash，可以长期缓存；HTML 应及时更新。

牌桌用到的 3D 模型在 `packages/client/public/models`，共约 4.2 MiB，由下面的命令从 `assets/models` 生成。小物件保留 512 px WebP 贴图并减面；两艘船的 UV 过碎，自动减面无法进行，所以先由 `scripts/bake-vertex-colors.mjs` 把贴图烘焙成顶点色、合并接缝上的重复顶点，再减到约 2.5 万三角形。既有模型已入仓，普通开发不必重新生成。

```bash
pnpm install                      # 脚本依赖 @gltf-transform/core 等，在根目录 devDependencies
bash scripts/prepare-models.sh    # 另需通过 npx 拉取 @gltf-transform/cli
```

界面改版的设计稿在 `packages/client/design/`，开发服务器下访问 `/design/chart-table.html`（平面稿）、`/design/table-3d.html`（3D 原型，`?deep` 为深渊语气，`?orbit` 可拖动视角，`?fp` 为第一人称）、`/design/round-table.html`（第一人称圆桌：地图嵌在桌子中央的框里，鼠标停在地图上会俯身细看；`?map` 保持俯身，`?deep` 为深渊语气）、`/design/models.html`（模型总览，`?only=ship-sails,helm` 只看指定模型）。这些页面不进入构建产物。

开发环境下页面上有 `window.__table`（当前牌桌的 `TableScene`），便于在控制台检查座位、物件和渲染开销。

## 存储

通过 workspace 脚本启动时，SQLite 默认位于 `packages/server/data/kraken.sqlite`。native 模块不可用时在同目录写 `events.jsonl`，控制台会提示降级原因。

若环境禁止依赖构建脚本，按安装器提示授权并重新构建 `better-sqlite3`；不要把 JSONL 冒烟通过当成 SQLite 磁盘事务验证通过。备份应针对实际启用的存储；备份文件包含完整私密事件，不能作为公开复盘文件发送。

数据库目前只有事件表，尚无房间 / 会话恢复服务。不要直接以旧规划中的 Docker/Caddy 示例部署，仓库并不存在这些配置。生产部署需要静态站点、WebSocket 反代、HTTPS、明确存储模式与数据卷；本次没有部署到外部服务器。

## 验证命令

```bash
pnpm typecheck
pnpm test
pnpm build
```

测试覆盖阵营、牌表、叛变、下班、关键牌效、私密投射、令牌、幂等事件键，以及新增的搜查确认、皈依历史知识、回洗牌序、短员随机替补和动作失败回滚。

启动服务端后，可运行真实 SDK 自动航行：

```bash
node scripts/smoke-game.mjs 5 quick
node scripts/smoke-game.mjs 7 quick
node scripts/smoke-game.mjs 7 long
node scripts/smoke-game.mjs 9 long
node scripts/smoke-game.mjs 11 long
```

脚本创建独立房间、建立真实 WebSocket、测试在线连接替换和离线恢复，然后按合法候选自动行动到终局，断言无动作拒绝、结束后阵营全揭示。每局随机，回合数和赢家会变化；它验证流程可达性，不验证策略胜率。脚本会在本地事件存储中留下测试记录。

`pnpm test` 同时运行服务端规则测试和客户端导演层测试（视图差分、节拍提交、积压合并）。

### 界面联调

调试动画时只需一个浏览器标签：在页面上创建房间，再让机器人补齐船员。机器人按延迟随机行动，自己是房主且满 5 人时会开局；会话保存在系统临时目录，重复运行同一命令会以原身份重连。

```bash
node scripts/bots.mjs <房间号> 4 1200   # 4 名机器人，平均 1.2 秒出手
```

页面地址加 `?slowmo=3` 会把所有编排放慢 3 倍，便于逐拍检查。
